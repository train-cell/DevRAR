# Wave two: native evidence and optional presentation/provider extensions

This continues the owner's explicit autonomous full-vision authorization. It
does not change the default local/offline mode or activate numerical grades.

## Modern Codex

Owner: source worker. Files: `codex_native.py`, legacy `syllogi.py`, and their
dedicated synthetic tests. The decoder is typed, Greeklish, and based on official
protocol definitions plus metadata-only inspection of a stable native file.

- Project `item_completed/AgentMessage` into the existing assistant pipeline,
  preserving its vendor ID and testing duplicate legacy projections in both
  orders. Inter-agent messages are separate and omit body/ciphertext.
- Keep command executions, patch metadata and collaboration records in a
  separate `codex_native` payload. There is no proven command-to-legacy-call
  join, so these do not inflate existing tool-call/result totals.
- A dedicated command accumulator can parse actual output/exit evidence with
  the same date filters and bounded citations. Its checks remain a separate
  observation channel. Agent targets are linked threads, not proven children.
- Deduplicate per-request usage by session/response identity and expose sums of
  recorded counters as an explicitly incomplete subset. Cumulative snapshots
  are not additive. Global token availability remains unchanged in this slice.
- Unknown substantive shapes retain partial coverage. No raw patches, encrypted
  bodies or automatically archived full streams are introduced.

Root integrates this payload into Markdown/HTML and reviews counts, attribution,
scope, missing values and actual native smoke results before publication.

## Optional cloud coaching

Owner: CLI worker, new `cloud.py` and synthetic tests only. Root owns eventual
CLI flags and report metadata integration. One explicit HTTPS endpoint/model
and a separate opt-in are required before any environment/key/network access.
Send only bounded, redacted `id/role/kind/excerpt`; omit source/session/locator
metadata and totals. Use the existing citation/role/prose validation boundary.

One request, no redirects/retries, bounded response, normal TLS and explicit
timeout. Key values never enter errors/reports. Invalid proposals preserve
rules/metrics and produce an explicit failed analysis plus useful partial exit.
No real cloud call is authorised for agent verification; mocks are synthetic.
